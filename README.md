# Sneaker Lab + BotShield MVP

Standalone Next.js + Supabase reference application for legitimate sneaker-release assistance and bot-defense testing.

## Scope

- Sneaker release watchlist and alerts
- Human-confirmed checkout handoff
- BotShield behavioral risk scoring
- Virtual queue simulation
- Server-side release/inventory controls

This project does **not** bypass CAPTCHAs, evade retailer anti-bot systems, rotate identities/proxies, create fake accounts, or automate purchases against third-party stores.
